## 新增阿里云 OSS 与 AWS S3 直连

在 **设置 → MarkToGo → 上传方式** 中选择 **阿里云 OSS** 或 **AWS S3**，填写桶信息并通过 Obsidian 秘密存储配置 Secret，即可直接上传图片，无需额外安装 PicList 或 Node.js。

- **阿里云 OSS**：使用 V4 签名上传，支持地域、Bucket、存储目录和自定义公开图片地址。
- **AWS S3**：使用 SigV4 签名，支持 AWS 官方标准通用桶及中国区域，可使用 CloudFront 等公开图片域名。
- **内容哈希命名**：图片采用完整 SHA-256 内容哈希命名，避免同名图片覆盖；缓存按上传方式和目标桶隔离。
- **保留既有配置**：从旧版升级继续使用 PicList，CLI、Node.js、配置路径及偏好保持。切换上传方式保留三套配置。
- **设置更易配置**：新增中英文帮助、云控制台和密钥管理快捷入口，修复上传方式选项的显示宽度。

原笔记和附件保持不变，已有 HTTP(S) 图片地址不会重新上传。复制文本、Windows 复制文件、按需保存和跨设备缓存继续可用。

### 更新与兼容

- 在 **设置 → 第三方插件 → 检查更新** 中更新 MarkToGo。
- OSS/S3 直连需要 **Obsidian 1.11.4+**；旧版 Obsidian 仍可使用 PicList。
- Secret 通过 Obsidian 秘密存储保存，插件设置仅保存引用名称；每台设备需要单独配置。
- 分享链接需要桶策略或公开图片域名允许匿名读取。插件不会修改桶权限或 ACL。
- AWS S3 当前不支持自定义兼容 Endpoint、STS Session Token 或目录桶；OSS 暂不支持 STS。
- 手动安装请下载本版本的 **main.js、manifest.json、styles.css**，放入插件目录后重载。

验证：62 项自动测试、3 项真实 PicList CLI 本地集成测试、类型检查、lint 和构建通过。OSS 已完成真实桶上传及缓存复用验证；S3 已通过 SDK 签名向量和本地 HTTP 传输测试，尚未覆盖真实 AWS 桶。

## Direct Alibaba Cloud OSS and AWS S3 uploads

Choose **Alibaba Cloud OSS** or **AWS S3** in **Settings → MarkToGo → Upload method**, configure your bucket and select a secret through Obsidian secret storage. Direct uploads require no separate PicList or Node.js installation.

- OSS V4 and AWS SigV4 authentication, including AWS China regions and optional public image domains.
- Full SHA-256 content names avoid filename collisions; destination-specific caches reuse successful uploads.
- Upgrades preserve existing PicList paths and preferences. Switching providers retains all three configurations.
- Settings include bilingual help, cloud console and key-management links, plus a dropdown layout fix.

Direct uploads require **Obsidian 1.11.4+**. PicList remains available on older versions. Secrets must be configured on each device. Public read access must be provided by your bucket policy or image domain; the plugin does not change permissions. Custom S3 endpoints, STS session tokens and S3 directory buckets are not supported.

Original notes, attachments and existing online image links stay unchanged. Text copying, Windows file copying, optional saving and shared upload caching remain available. Manual installations need **main.js**, **manifest.json** and **styles.css**.

Validation: 62 automated tests and 3 local PicList CLI integration tests passed, together with type checks, lint and builds. Real OSS uploads and cache reuse were verified. S3 was checked against SDK signature fixtures and local HTTP transport; real AWS bucket testing remains outstanding.
