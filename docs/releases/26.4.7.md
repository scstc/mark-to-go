## 简体中文

- 新增 Emotion Ball 小助手：设置页可预览表情，导出进度和结果弹窗显示对应状态。
- 眼神随所在窗口内的鼠标移动，保留思考、成功彩带和休息等原版表情效果。
- 支持暂停动画和系统减少动画偏好；离开可视区域、关闭界面或卸载插件时停止并释放动画资源。
- 表情初始化失败时回退文字状态，避免装饰组件影响分享；修复异常时笔记无法重试的问题。
- 加强发布检查：插件与第三方代码严格 lint，核对构建产物、版本和许可声明，审计运行依赖；将每次功能修改必须检查的要求写入 AGENTS.md。

升级保留原有 PicList、阿里云 OSS、AWS S3 配置与上传缓存。本次没有新增遥测、远程脚本或表情服务请求。

Emotion Ball 来自 [sam70361/aora-bot](https://github.com/sam70361/aora-bot)，其引擎与视觉形象适用独立的[非商业许可](https://github.com/scstc/mark-to-go/blob/26.4.7/src/vendor/emotion-ball/LICENSE)和[使用声明](https://github.com/scstc/mark-to-go/blob/26.4.7/src/vendor/emotion-ball/NOTICE.md)。球形角色仅供个人技术学习与研究，禁止商业用途；这些第三方内容不属于 MarkToGo 第一方代码的 0-BSD 许可范围。完整声明保留在插件发布文件中。

验证：70 项自动测试、39 处 Node 类型解析、严格 lint（0 错误、0 警告）和生产构建检查通过，并在 Obsidian 中验证鼠标注视、表情、暂停、减少动画及关闭清理。运行依赖审计为 0 漏洞；通过兼容更新消除了开发依赖的 3 项高危告警，开发工具链仍有 23 项中等告警，详见[开发说明](https://github.com/scstc/mark-to-go/blob/26.4.7/docs/advanced.zh-CN.md)。文件系统、子进程、剪贴板等实际功能对应的社区能力提示仍可能显示，不能将本地检查通过等同于社区报告完全清零。

## English

- Add an Emotion Ball assistant to the settings preview, export progress notices and result dialog.
- Follow the pointer within the owning window, with the original thinking, celebration and resting effects.
- Respect pause controls and reduced-motion preferences; stop and dispose animations when offscreen, closed or unloaded.
- Fall back to readable status text when animation initialization fails, and keep notes available for retry after an initialization error.
- Strengthen release checks with strict plugin and vendor linting, bundle and version validation, preserved notices and production dependency audits; record the required review workflow in AGENTS.md.

Existing PicList, Alibaba Cloud OSS and AWS S3 settings and upload caches are preserved. No telemetry, remote scripts or expression-service requests are added.

Emotion Ball comes from [sam70361/aora-bot](https://github.com/sam70361/aora-bot). Its engine and character visuals have a separate [non-commercial license](https://github.com/scstc/mark-to-go/blob/26.4.7/src/vendor/emotion-ball/LICENSE) and [usage notice](https://github.com/scstc/mark-to-go/blob/26.4.7/src/vendor/emotion-ball/NOTICE.md). The ball-character visuals are for personal technical study and research only; commercial use is prohibited. These third-party materials are outside the 0-BSD license covering MarkToGo's own code. The complete declarations are retained in the plugin bundle.

Validation: 70 automated tests, 39 Node import type checks, strict lint with no errors or warnings, and production build checks passed. Pointer tracking, expressions, pause, reduced motion and disposal were verified in Obsidian. Production dependencies have no reported vulnerabilities. Compatible updates removed three high-severity development dependency findings; 23 moderate development-toolchain findings remain documented in the [advanced guide](https://github.com/scstc/mark-to-go/blob/26.4.7/docs/advanced.md).
